# Harbor Bridge installation

Lumenvale Home Systems support handbook. All products and policies are fictional.

The Harbor Bridge requires wired Ethernet for its uplink. It cannot join a Wi-Fi network as a client.

A single Harbor Bridge supports 24 paired endpoints. A repeater counts toward that limit just like a sensor.

Hold the setup button for 3 seconds to start pairing. A 12-second hold instead resets pairing and network settings.

The status light pulses white while booting and stays blue once the bridge has a local IP address.
