# Stillwater valve controller

Lumenvale Home Systems support handbook. All products and policies are fictional.

The Stillwater Valve Controller fits quarter-turn handles only. A round multi-turn wheel requires a different actuator.

Its internal backup provides up to two close cycles after power loss. The backup does not reopen the valve.

Pull the orange clutch to disengage the actuator for manual operation. Re-engage it before running calibration.

The controller starts a new calibration only when the valve is fully open and its status light is steady green.
